# Assignment
Assignment 1
## Title
How the Internet Delivers a Web Page Using TCP/IP Protocol Stack
## Objective
To understand how the Internet delivers a web page using TCP/IP, DNS, HTTP, and TCP
## Solution
The browser uses DNS to find the server's IP address, sends an HTTP request through the TCP/IP protocol stack, and receives the webpage reliably from the server.
## Output
The requested YouTube webpage is successfully displayed in the user's browser after reliable data transmission.
## Conclusion
Application-layer protocols such as DNS, HTTP, and TCP work together to provide reliable and efficient Internet communication.

Assignment 2
## Title 
LAN, Ethernet & Wireless Network Investigation
## Objective
To analyze how the data-link layer provides framing, MAC addressing and shared-media access, with emphasis on Ethernet, wireless LANs and Mobile IP.
## Solution
Each question is answered with theory, diagrams and tables covering the data-link layer, the Ethernet frame, switch MAC learning, hub/switch/bridge, CSMA/CD and CSMA/CA, a lab WLAN design, Mobile IP, and a wired vs 802.11 frame comparison
## Output
A 5-page PDF with an Ethernet frame diagram, a switch forwarding-table example, a WLAN topology, a Mobile IP flow diagram and comparison tables, with no Wireshark captures since Q3 was skipped.
## Conclusion
Switched full-duplex Ethernet has made CSMA/CD largely unnecessary, while wireless needs CSMA/CA and a richer 802.11 frame, and Mobile IP keeps connections alive when a device changes networks.
